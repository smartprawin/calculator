# Mobile App (PWA + Capacitor)

This guide explains how to turn the existing static calculator site into an
installable **Progressive Web App (PWA)** and, from the same project, a native
**Android app** via **Capacitor** — with no rewrite of the current HTML/CSS/JS.

## Goal

- **PWA**: installable on home screen + works offline in a browser.
- **Capacitor**: wrap the same web code into a real Android app for the Play Store.
- **Same project**: all calculator pages, Tamil i18n, theming, and SEO are reused.

## Architecture

Everything stays in the current project folder. Capacitor copies the static
files into a native shell; no separate repository is needed.

```
Simple EMI calculator/
├─ index.html, emi.html, tax.html, ebbill.html, privacy.html   (existing site)
├─ common.js, emi.js, ebbill.js, tax.js, style.css             (existing assets)
├─ favicon.png, og-image.png
├─ manifest.webmanifest        (PWA)
├─ sw.js                       (service worker)
├─ capacitor.config.ts         (Capacitor config, webDir: ".")
├─ package.json                (capacitor dev dependencies)
└─ android/                    (generated by `cap add android`)
```

## Prerequisites

- **Node.js + npm** (to install and run Capacitor CLI).
- **Android Studio + Android SDK** (only needed for the final Android build /
  `cap add android`). The PWA part needs neither.
- A static web project (already have one).

## Step 1 — PWA (works in any modern browser)

### 1a. `manifest.webmanifest`

```json
{
  "name": "Calculators - EMI, EB Bill, Income Tax",
  "short_name": "Calculators",
  "description": "EMI, electricity bill and Indian income tax calculators.",
  "start_url": "index.html",
  "scope": ".",
  "display": "standalone",
  "background_color": "#e0e7ff",
  "theme_color": "#2563eb",
  "icons": [
    { "src": "favicon.png", "sizes": "256x256", "type": "image/png" }
  ]
}
```

### 1b. Link the manifest + theme in each HTML `<head>`

```html
<link rel="manifest" href="manifest.webmanifest">
<meta name="theme-color" content="#2563eb">
```

### 1c. `sw.js` (offline cache)

```js
const CACHE = 'calc-v1';
const ASSETS = [
  'index.html', 'emi.html', 'tax.html', 'ebbill.html', 'privacy.html',
  'common.js', 'emi.js', 'ebbill.js', 'tax.js', 'style.css',
  'favicon.png', 'og-image.png', 'manifest.webmanifest'
];

self.addEventListener('install', (e) => {
  e.waitUntil(caches.open(CACHE).then((c) => c.addAll(ASSETS)));
  self.skipWaiting();
});

self.addEventListener('activate', (e) => {
  e.waitUntil(caches.keys().then((keys) =>
    Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k)))));
  self.clients.claim();
});

self.addEventListener('fetch', (e) => {
  if (e.request.method !== 'GET') return;
  e.respondWith(
    caches.match(e.request).then((hit) => hit || fetch(e.request))
  );
});
```

### 1d. Register the service worker

Add at the end of `common.js` (runs on every page):

```js
if ('serviceWorker' in navigator) {
  window.addEventListener('load', () => {
    navigator.serviceWorker.register('sw.js').catch(() => {});
  });
}
```

## Step 2 — Capacitor (native Android app)

### 2a. `package.json`

```json
{
  "name": "simple-calculators",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "build": "node scripts/copy-web.js"
  },
  "dependencies": {
    "@capacitor/core": "^6.0.0"
  },
  "devDependencies": {
    "@capacitor/cli": "^6.0.0",
    "@capacitor/android": "^6.0.0"
  }
}
```

### 2b. `capacitor.config.json`

```json
{
  "appId": "in.simplecalculator.app",
  "appName": "Calculators",
  "webDir": "www"
}
```

Capacitor requires a real subfolder for `webDir` (`.` is rejected), so a small
`scripts/copy-web.js` copies the site's static files into `www/` (gitignored).
This also keeps `node_modules`, `android/`, and the `docs/` folder out of the
bundled app.

### 2c. Build the native project

```bash
npm install
npx cap add android      # requires Android Studio + SDK
npm run build            # copies web files into www/
npx cap sync             # copies www/ into android/app/src/main/assets/public
npx cap open android     # opens Android Studio
```

After editing any web file, re-run `npm run build && npx cap sync`. Then
build/run from Android Studio (or `npx cap run android` with a device/emulator).

## Notes & gotchas

- **Offline inside the app**: the Android WebView does not run service workers,
  but Capacitor bundles the assets locally, so the app is offline-capable by
  default. The service worker matters only for the browser/PWA install path.
- **AdSense**: the `pagead2.googlesyndication.com` script may not serve ads
  reliably inside a WebView. Expect in-app ad behaviour to differ from the live
  site.
- **Relative paths**: keep all asset references relative (e.g. `style.css?v=2`,
  `common.js?v=2`) so they resolve both on the web and inside the native shell.
- **Tamil / ?lang=ta**: still works — `common.js` reads the `?lang=ta` param
  inside the WebView too. For a default Tamil app build, set the start URL or
  detect locale in `common.js`.
- **Versioning**: when you change `style.css` / `common.js`, bump the `?v=` query
  and run `npx cap sync` so the native app picks up new assets.
