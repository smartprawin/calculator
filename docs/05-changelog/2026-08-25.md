# Changelog — 2026-08-25 (Session)

## Food Calculator — Enhancements

**Files:** `food.html`, `food.js`, `style.css`, `scripts/copy-web.js`

### What's new
- **15 raw vegetables & salads added** to FOOD_DB: Cucumber, Tomato, Onion, Lettuce, Broccoli, Cauliflower, Raw carrot, Raw beetroot, Mixed salad, Sprouts (moong), Capsicum (raw), Spinach (raw), Radish, Celery, Avocado
- **60+ additional food items** including Chinese, grilled, fast food, sweets, and serving-size portions
- **Searchable combobox** replacing dropdown: type to search, shows top 10 matches with calorie info
- **Unit selection** with 12 options: g, ml, pcs, cup, spoon, tbsp, tsp, serving, bowl, plate, glass, slice
- **Range sliders** for age, weight, and height inputs (synced with numeric inputs)
- **Target vs Actual Comparison table** showing:
  - Calories, Protein, Carbs, Fat, Fiber (target vs actual with +/- diff)
  - Water, Sugar (max), Saturated Fat (max)
  - Color-coded status: Green (under), Orange (warning), Red (over)
- **Mobile-optimized layout:**
  - Food add row stacks vertically on mobile
  - Segmented controls wrap on small screens
  - Cards have consistent min-height across breakpoints
  - Comparison table responsive with smaller fonts
- **food.html and food.js added to copy-web.js** for mobile sync

### Bug fixes
- Fixed food calculator not appearing in mobile app (missing from copy-web.js whitelist)
- Server now runs in background without opening new PowerShell windows
