# Changelog — 2026-08-23 (Session)

## Weight Loss Planner — fixed-time goal + workout plan + chart

**Files:** `weightloss.html`, `weightloss.js`, `style.css`, `common.js`

### What changed
- **Goal Time input** (slider + textbox, weeks) so the user can fix the target
  duration instead of deriving it from the deficit.
- **Exercise to Close the Gap** model: lists all 8 activities with the
  minutes/day each needs to hit the goal for the chosen time + daily intake
  (replaces the earlier single-pick "Workout (optional)" chip UI). Tap any row
  to select it; impractical (>2 hr/day) rows are flagged.
- **Projected Weight chart** upgraded to a labeled area chart: weight/weeks axes,
  dashed goal line, start/end weight markers, midpoint marker, and goal date.
- **Auto-plan logic** (`updateAutoPlan` / `renderWorkoutList`) computes required
  daily deficit/burn from fixed time + intake and reports feasibility
  (Feasible / Not feasible / low-intake warning).
- **i18n**: added keys for goal time, required deficit/burn, plan status, and
  suggestions in `common.js`.

### Bug fix
- Restored the removed `workoutBurnText` element that caused `render()` to throw
  (null `textContent`) and leave Time to Goal / Goal Date / Deficit / BMI blank.

### Mobile
- Rebuilt and reinstalled the signed Capacitor APK (`cap sync android` →
  `assembleRelease` → `adb install`) with the updated web assets.
