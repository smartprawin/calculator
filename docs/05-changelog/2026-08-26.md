# Changelog — 2026-08-26 (Session)

## Food Calculator — Comparison, Meal Plan & Units

**Files:** `food.html`, `food.js`, `style.css`, `downloads/app-release.apk`

### Bug fixes (Target vs Actual Comparison)
- Fixed inverted status for **Protein** and **Fiber** (minimum targets were shown green when under target).
- Fixed bogus **Water "actual"** formula (`kcal * 0.001` → ~2 ml); now shown as target-only.
- Fixed false **mismatches when nothing is logged** — Actual/Status now show `-` until food is entered.
- Fixed **calorie status ignoring the goal** (under target is now bad when "gain", good when "lose", "on track" when "maintain").
- Fixed column **alignment** — Target/Actual/Status now consistently left-aligned.

### New features
- **Suggested Meal Plan**: builds a sample day (Breakfast → Dinner) scaled to the user's target calories, with per-meal and macro totals vs target.
- **`nos` (pieces) unit** re-added with per-food `piece` weights (e.g. Parotta 70 g, Banana 118 g, roti 35 g) so `2 nos parotta` converts correctly. Removed earlier because `pcs` mapped 1 piece = 1 g.
- **Sugar (max) and Saturated Fat (max) actuals**: derived per food from composition/food group and summed from the log, with over/under status.
- **Side-by-side layout**: Comparison table and Suggested Meal Plan now sit side by side on wide screens, stacking on mobile.
- Rebuilt and reinstalled the Android APK (food card now present on home screen).

### Database
- Added ~170 food items (millets/fasting, pasta, beverages, dairy, confectionery, more fruits/nuts/seeds, legumes, non-veg, sauces, soups).
- Added `piece`, `satFat`, `sugar` awareness to the food-log math.
