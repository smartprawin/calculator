# Changelog — 2026-08-24 (Session)

## Food Calculator — New Calculator

**Files:** `food.html`, `food.js`, `common.js`, `style.css`

### What's new
- **Full food calculator** with two modes: Nutrition and Monthly Budget
- **Nutrition mode:** Calculates BMR (Mifflin-St Jeor), TDEE, target calories (lose/maintain/gain), macro split (protein 1.8g/kg, fat 25%, carbs remainder), fiber, water, sugar, sat-fat
- **Food Calorie Counter:** 191 Indian foods (per 100g) with full macros (kcal, protein, carbs, fat, fiber) sourced from IFCT 2017 and USDA data
- **Monthly Budget planner:** Line-item food expense calculator with daily/weekly/monthly frequency
- **Pie chart** for macro breakdown (protein/carbs/fat)
- **i18n:** English + Tamil translations for all UI elements

### Data sources
- IFCT 2017 (National Institute of Nutrition, Hyderabad)
- USDA FoodData Central

## Irregular Part-Payment Calculator — Savings Comparison

**Files:** `irpart.html`, `irpart.js`

### What's new
- **Prepayment Savings Summary** card showing:
  - Without Prepayments (total payment if no part-payments)
  - With Prepayments (actual total payment)
  - You Save (difference, green if positive, red if negative)
  - Months Saved (tenure reduction)
- Comparison calculated by building baseline schedule without prepayments and comparing with current schedule
- Savings card hidden when inputs are invalid
